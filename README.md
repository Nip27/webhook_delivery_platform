# WebhookFlow — Webhook Delivery Platform

> ⚠️ Under active development. See [CHANGELOG](./CHANGELOG.md) for progress.

A production-style event-driven webhook delivery system.

## Tech Stack

### Backend

- Java 21
- Spring Boot 3.2
- PostgreSQL 16
- Redis 7

### Frontend

- React 18
- Tailwind CSS
- Vite

### DevOps

- Docker Compose
- GitHub Actions

## Status

🚧 Building in public — following real product-company engineering workflows.

```bash
cp .env.example .env
docker compose up -d
```
